  • 1階が負担する重量 Σw₁ = W1 + W2 = 314,621 N（314.62 kN）
  • 2階が負担する重量 Σw₂ = W2 = 183,901 N（183.90 kN）

下の階は上の階すべてを支えるため、Σw は累計で扱います。 （階ごとの重量をそのまま用いると必要壁量を小さく見積もります。 本計算では検算エンジン側でもこの関係を検査しています。）
